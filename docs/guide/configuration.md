# Configuration

Settings come from `src/backend/.env`.

| Variable | Default | Description |
| --- | --- | --- |
| `PORT` | `3001` | Port the server listens on. |
| `SESSION_HOURS` | `24` | How long a session lasts. |
| `SCHOOL_EMAIL_DOMAIN` | `nushigh.edu.sg` | Accounts on this domain are approved automatically. |
